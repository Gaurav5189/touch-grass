## Key Architecture Decisions

### 1. Feature-Based Architecture
- Each identification mode (bird, photo, history) is a self-contained feature
- Shared utilities and UI components in `shared/`
- Workers isolated for non-blocking inference

### 2. Web Worker Inference
- ONNX inference runs in dedicated Web Worker
- Main thread stays responsive for UI
- Message passing for input/output tensors

### 3. Progressive Model Loading
- Models downloaded on first use (not at app load)
- Streamed download with progress to IndexedDB
- Regional packs reduce initial download size

### 4. Privacy-First Data Flow
- No network requests for inference
- Optional GPS only with explicit consent
- Export is user-initiated, local-only

### 5. Graceful Degradation
- WebGPU → WASM → TF.js fallback chain
- Reduced model quality on low-end devices
- Clear messaging when features unavailable
